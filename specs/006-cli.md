# CLI Specification

## Objective

Provide a reproducible command line interface.

---

# Global Options

- `--config PATH` path to a TOML configuration file (default: `bcra.toml` if present).
- `--log-level LEVEL` override log verbosity.

---

# Commands

## fetch

```bash
bcra-pagos-minoristas-xlsx-to-parquet fetch
```

Run discovery and download stages. Produces raw XLSX files and download metadata.

## parse

```bash
bcra-pagos-minoristas-xlsx-to-parquet parse
```

Parse downloaded XLSX files into structured datasets with parsing metadata.

## build

```bash
bcra-pagos-minoristas-xlsx-to-parquet build
```

Normalize and store datasets in Parquet or Delta Lake.

## run

```bash
bcra-pagos-minoristas-xlsx-to-parquet run
```

Execute the complete pipeline: discovery, download, parse, normalize, store.

---

# Requirements

## C1
CLI must be idempotent.

## C2
CLI must support configuration files.

## C3
CLI must expose structured logs.

## C4
CLI must return non-zero exit codes on failure.

## C5
CLI must surface pipeline metadata per command.

---

# Logging

CLI logs must include:
- command name
- execution duration
- result status
